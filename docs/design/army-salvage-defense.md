## 玩法概述

废土战场经营防御：泥潭里散落着坠机与武器残骸，主角把残骸拖到回收站粉碎成金锭与弹药；弹药供给蓝色炮塔抵御下方涌来的红色敌潮；攒钱解锁路障、新炮塔和能量塔，最终打捞泥潭中央的整架飞机（开局即可见的长期锚点）完成防线升级。

- 小循环（秒级动作反馈）：走近残骸自动拉拽 → 拖到回收站 → 粉碎为金锭/弹药入账（弹药计数跳动）
- 大循环（playable 全程弧线）：解锁路障/炮塔/能量塔 xN → 火力兑现压制敌潮 → 打捞大飞机 → 防线完全体 → CTA

## 交互与引导

- 手指引导：定向引导链——可买的目标牌 > 背满/拖住残骸时指向回收站 > 否则指向最近残骸。
- **操作归属**：主角移动由玩家点击地面驱动，停手即停在原地；走近残骸自动拉拽、拖到回收站自动粉碎（范围自动交互）；炮塔自动射击是玩家建造获得的自动化；敌潮是压力源（非玩家资产，不受此原则约束）。无自动结算——大飞机打捞（终极目标）必须玩家亲手触发。原片为拖拽绳索，playable 简化为点击移动。
- **目标链**：教学残骸（免费）→ 30 金解锁路障/炮塔 → 解锁能量塔（弹药上限 30→80）→ 打捞大飞机（终极目标，触发防线完全体结算）。价格牌与飞机残骸开局全部可见，链条无断档 ✓。
- **长期锚点**：泥潭中央的整架飞机残骸（第一帧可见、最后才可打捞）；下方持续逼近的红色敌潮（压力锚点）。
- **地图尺度**：主角高约占画面 14%（打捞特写）/ 5.5%（全景），地图分三层：泥潭打捞区(上) → 基地生产区(中，回收站+能量塔) → 防线与敌潮(下)。
- 容错处理：不操作时主角停在原地、手指持续引导；已建炮塔继续自动射击（玩家买来的自动化）；敌潮在 playable 中为演出压力，不会真正击穿防线（无失败挫败）。
- 胜利条件：完成目标链并亲手打捞大飞机（无失败路径）。
- 结算卡：标题 `DEFENSE ONLINE!`（拟写），副标题防线主题，CTA `PLAY NOW`。

## 与模板的差异点

> 按优先级排序；本次策划案交付不含实现，落地时逐条决策。

1. **敌潮防御演出**（红色人海 + 蓝色炮塔自动射击，frame 03/05）：这是本案例压力感的核心。crew 行为树可复用：炮塔=固定位工人换「索敌→攻击」树，敌潮=批量矿脉（stock=血量）向防线推进；或复用 towerdefense 模板的敌人波次逻辑。建议作为 boom 演出主体落地。
2. **弹药经济**（x/30 → x/80 计数条）：回收产出分流为金锭（购买）+弹药（火力），HUD 加一条弹药计数。可简化为纯视觉计数，不参与结算。
3. **拖拽绳索表现**：残骸被拉动时的绳索与倾斜动画——占位阶段用残骸位移+火花表达，留待美术。
4. **大件多绳打捞**（金色轮廓引导，frame 06）：终极目标（vault）的专属演出，可用轮廓高亮+多段位移近似。
5. 敌潮真实击穿防线的失败分支——playable 无失败原则，不落地。
