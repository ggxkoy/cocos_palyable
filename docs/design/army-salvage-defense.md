## 封面

- **玩法卖点**：打捞经营 + 防线塔防（战斗压力型）
- **大纲**
  1. 开局主角站在岸边用绳子从大泥潭里拉废弃物资，泥潭是前期唯一的物资来源。
  2. 废料背到回收机卸货，机器一件件加工成子弹包堆在出料口；主角把子弹包背到前线炮塔，炮塔才有子弹开火。
  3. 丧尸成波涌来撞围墙；只有杀敌才掉金币，金币升级绳子的长度与质量，够得着泥潭深处更大的残骸，换更多子弹杀更多敌。
  4. 满级绳子才能打捞泥潭最深处的大飞机（开局第一帧就看得见的长期锚点）；捞起即触发敌潮+BOSS 总攻，清场获胜。
  5. 围墙耐久归零即失败，可复活重试 1 次；再次被击破则终局。

## 分析结论（流水线保留章节）

- **目标结构（动机轴）**：战斗压力型。判断依据：画面下方持续有红色敌潮推进，弹药计数会被打到 0——存在真实的生存压力，因此小循环必须服务于「收集资源 → 转化为战斗力 → 战斗验证」，而非纯解压经营。
- **操作归属**：主角移动**只**由虚拟摇杆驱动（按下出现摇杆、拖动移动、松手即停），无自动走位、无自动结算。范围自动交互：走到残骸够得着的岸边自动拉绳、走近掉落物自动拾取、贴着回收机自动卸货、贴着炮塔自动交付子弹、范围内自动攻击。自动化只能靠购买获得（雇佣工兵跑废料线、炮塔自动射击）。敌潮是压力源，不受此原则约束。
- **目标链**（非线性）：HIRE 15 → ROPE+ 30 → HIRE 45 → ROPE+ 60 → SALVAGE 80。五块目标牌开局全部在场且全部可买，顺序由价格大小自然引导而非程序强制；SALVAGE 额外挂状态门槛（绳子满级才可买）。每个循环闭合时下一目标已在场上 ✓。
- **长期锚点与地图尺度**：大飞机残骸横在泥潭最深处（z=-17.5），第一帧可见、最后才可打捞；红色敌潮与围墙是压力侧锚点。主角身高 1.7m，地面 11×44m，主角约占画面高度 5.5%（全景）——地图按三屏分层：北=泥潭打捞区、中=回收转换区、南=防线。
- **模板映射（操作轴）**：3D 模块拼装，`playables/salvage3d/` + 场景 `assets/scenes/salvage3d.scene`（**不是** 2D 的 crew 模板）。模块清单见文末。

## 资源循环

- **核心资源**：废料 scrap1/2/3（来源：泥潭分级残骸，唯一来源）、子弹包 ammo1/2/3（来源：回收机加工废料）、弹药（来源：子弹包送达炮塔）、金币（来源：**只有击杀敌人掉落**）。
- **循环 1 · 打捞补给线（开局即在）**：
  站岸边拉绳（绳长够得着才行）→ 残骸拉出、散出对应等级废料 → 主角/工兵背起 →
  贴回收机卸货进队列 → 机器按 0.35s/件加工成**子弹包实体**堆在出料口（堆满 10 件停机）→
  主角把子弹包背在身后 → 送到前线炮塔 → 入弹池 → 炮塔开火。
  **弹药不是抽象计数**：不搬运，前线就没有子弹，生产线还会自己憋停。
- **循环 2 · 战斗兑现（弹药到位后出现）**：
  炮塔杀丧尸 → 敌人倒地掉金币 → 主角捡金币 → 站上目标牌驻留购买 →
  雇佣工兵（废料线自动化）/ 升级绳子（长度+质量）→ 够得着更深处更高级的残骸 →
  更值钱的子弹包 → 更多弹药 → 杀更多敌 → 更多金币。
- **战斗循环**：击杀 → 金币 → 升级绳子 → 更高级废料 → 更多弹药 → 击杀。
- **核心逻辑**：操作重心从「拉绳打捞」转移到「跑补给线 + 抢金币」；压力从「弹药见底」转移到「围墙耐久见底」。终局大飞机军火库直接并入防线，把玩家从跑腿中解放出来看总攻演出。

### 数值设计

**大小关系原则**（可调绝对值，不许破坏关系）：
1. 终极目标（打捞大飞机 80）最贵，且额外需要绳子满级——钱到位也得能力到位。
2. 目标链价格严格递增：15 < 30 < 45 < 60 < 80，用价格自然引导顺序而不强制。
3. 绳长逐级放大且必须跨过对应残骸的深度：一级只够岸边小件，二级够中件，三级才够大件与大飞机。
4. 废料等级越高 → 拉得越久、出得越多 → 换的子弹包面值越大（4 < 6 < 9）。
5. 敌人对围墙伤害 小兵 : BOSS = 1 : 10（对标案关系）。
6. 一背子弹包（5×ammo1=20 发）应显著大于一波渗透（2 只小兵 ≈ 4 发）——补给一趟能顶好几波，否则玩家会被跑腿淹没。
