## 玩法概述

废土战场经营防御：泥潭里散落着坠机与武器残骸，主角把残骸拖到回收站粉碎成金锭与弹药；弹药供给蓝色炮塔抵御下方涌来的红色敌潮；攒钱解锁路障、新炮塔和能量塔，最终打捞泥潭中央的整架飞机（开局即可见的长期锚点）完成防线升级。

- 小循环（秒级动作反馈）：站上岸边拉绳打捞泥潭残骸 → 废料背身 → 回收站【废料换弹药】（等级越高的废料换的子弹越多）
- 双货币咬合（正循环）：弹药让炮塔杀丧尸 →【金币只来自杀敌掉落】→ 金币升级绳子（长度+质量）→ 够得着更深处更高级的残骸 → 换更多弹药 → 杀更多敌
- 大循环（playable 全程弧线）：一级绳捞小件起步 → 雇佣/升绳 xN → 满级绳打捞大飞机（终极目标）→ 敌潮+BOSS 总攻、围墙攻防 → 清场 → CTA

## 交互与引导

- 手指引导：定向引导链——可买的目标牌 > 背满/拖住残骸时指向回收站 > 否则指向最近残骸。
- **操作归属**：主角移动由虚拟摇杆驱动（按下出现摇杆、拖动移动、松手即停）；走近残骸自动拉拽、拖到回收站自动粉碎（范围自动交互）；炮塔自动射击是玩家建造获得的自动化；敌潮是压力源（非玩家资产，不受此原则约束）。无自动结算——大飞机打捞（终极目标）必须玩家亲手触发。购买=走上目标牌站定驻留（与原片一致）。
- **目标链**（非线性，价格引导顺序）：HIRE 15 → ROPE+ 30 → HIRE 45 → ROPE+ 60 → SALVAGE 80（大飞机，需满级绳子才可购买——requirement 门槛）。所有目标牌开局全部在场、全部可买，顺序由价格大小自然引导，不做强制 ✓。
- **长期锚点**：泥潭中央的整架飞机残骸（第一帧可见、最后才可打捞）；下方持续逼近的红色敌潮（压力锚点）。
- **地图尺度**：主角高约占画面 14%（打捞特写）/ 5.5%（全景），地图分三层：泥潭打捞区(上) → 基地生产区(中，回收站+能量塔) → 防线与敌潮(下)。
- 容错处理：不操作时主角停在原地、引导持续；已建炮塔继续自动射击（玩家买来的自动化）；雇员自动跑打捞小循环。
- **没有子弹就无法攻击**：主角与炮塔共用一个弹池，主角每次近战/射击消耗 1 发；弹药打空时主角无法索敌、炮塔停火——只能回泥潭捞废料换子弹（压力循环的核心）。
- **失败与重试**（对标案「敌人攻击机制」）：防线上有一道围墙，敌人抵墙改为攻墙——小兵挠 1 点、BOSS 砸 10 点（1:10 伤害关系）；耐久归零=击破=失败结算，可点 REVIVE 复活重试 1 次（修满围墙、击退现存敌潮，不掉金币）；再次击破则终局。
- 胜利条件：满级绳子亲手打捞大飞机 → 敌潮+BOSS 总攻被清场（状态驱动结算，无秒表）。
- 结算卡：胜利 `DEFENSE ONLINE!` / 失败 `WALL BREACHED!` + REVIVE 按钮（拟写），CTA `PLAY NOW`。

## 与模板的差异点

> 按优先级排序；本次策划案交付不含实现，落地时逐条决策。

1. **敌潮防御演出**（红色人海 + 蓝色炮塔自动射击，frame 03/05）：这是本案例压力感的核心。crew 行为树可复用：炮塔=固定位工人换「索敌→攻击」树，敌潮=批量矿脉（stock=血量）向防线推进；或复用 towerdefense 模板的敌人波次逻辑。建议作为 boom 演出主体落地。
2. **弹药经济**（x/30 → x/80 计数条）：回收产出分流为金锭（购买）+弹药（火力），HUD 加一条弹药计数。可简化为纯视觉计数，不参与结算。
3. **拖拽绳索表现**：残骸被拉动时的绳索与倾斜动画——占位阶段用残骸位移+火花表达，留待美术。
4. **大件多绳打捞**（金色轮廓引导，frame 06）：终极目标（vault）的专属演出，可用轮廓高亮+多段位移近似。

   围墙耐久 + 击破失败 + 复活重试 1 次（`DefenseSim.wall` / `GoalChainSim.fail/revive`）。
