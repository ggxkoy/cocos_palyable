## 玩法概述

冰原营地经营：营地外堆着海量冻鱼（资源），渔夫把鱼搬上切鱼台加工成鱼排、送到出餐台换钱；攒钱踩目标牌解锁自动切鱼机、传送带、晾鱼架和新雇员，营地逐步繁荣；结尾白熊袭营、士兵自动迎战，冰湖中巨鲸浮出（长期威胁/下一阶段预告）导向 CTA。

- 小循环（秒级动作反馈）：搬鱼 → 切鱼台加工 → 出餐台变现（现金堆叠可见增长）
- 大循环（playable 全程弧线）：解锁自动化/雇员/扩建 xN → 营地繁荣 → 白熊来袭防御成功 → CTA

## 交互与引导

- 手指引导：定向引导链——可买的目标牌 > 背满时指向出餐台 > 否则指向最近鱼堆。
- **操作归属**：主角（渔夫队长）移动由玩家点击地面驱动，停手即停在原地；走近鱼堆自动切鱼、背满走近出餐台自动变现（范围自动交互）；雇员的全自动小循环是玩家花钱雇来的。无自动结算——篝火盛宴（终极目标）必须玩家亲手点开。原片为摇杆走位，playable 简化为点击移动。
- **目标链**：免费雇渔夫 → 150 金雇第二渔夫 → 200 金解锁第二鱼区（对应原片扩建） → 300 金点燃篝火盛宴（终极目标，触发结算演出）。原片目标牌开局即全部可见，链条无断档 ✓。
- **长期锚点**：营地外的巨型鱼堆（第一帧可见，资源之海）；冰湖与湖中巨鲸（后段浮现，下一阶段威胁）。playable 中金库/篝火从第一帧矗立在地图顶部。
- **地图尺度**：主角高约占画面 8-11%（近景）/ 6%（远景），地图分四层：鱼堆资源区(上) → 围栏加工区(中) → 出餐/顾客区(下) → 冰湖(底，远期钩子)。
- 容错处理：不操作时主角停在原地、手指引导持续指向下一步；已雇佣的雇员继续自动小循环（玩家买来的自动化）。**无任何自动推进**。
- 胜利条件：玩家完成目标链并亲手点燃篝火盛宴（无失败路径；结尾战斗为演出）。
- 结算卡：标题 `SURVIVED!`（拟写），副标题生存主题，CTA `PLAY NOW`。

## 与模板的差异点

> 按优先级排序；本次策划案交付不含实现，落地时逐条决策。

1. **结尾战斗验证**（白熊袭营，士兵自动迎战，frame 06）：crew 行为树换目标即可实现（矿脉 stock=熊的血量、士兵=换皮工人），建议作为 boom 演出的替代或叠加。
2. **二段加工链**：原片是 鱼堆→切鱼台(加工)→出餐台(变现) 两跳；crew 当前是 采集→直接入库一跳。可给 depot 增加"加工耗时"参数近似，或本次直接映射为一跳（视觉上由美术表达加工）。
3. **顾客队列**：出餐台前顾客排队买走鱼排（frame 03）——纯表现层增强，不影响经济数值。
4. **传送带演出**：鱼排沿传送带流转（frame 03）——表现层增强，留待美术阶段。
5. 摇杆控制主角、冰湖巨鲸 boss 战——超出 playable 单点循环范围，不落地。
