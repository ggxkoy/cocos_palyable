## 封面

- **玩法卖点**：放置采矿经营（解压经营型，无战斗）
- **大纲**
  1. 开局是等距视角的矿区：金矿盘 + 地面散落金条，玩家第一步就是把发光金堆收进口袋。
  2. 收集期共 3 处发光金堆，每收一处金币入账，收满即进入雇佣期。
  3. 攒够金币后按下 HIRE，把钱投给基地，僵尸矿工队伍加入、基地升级（顶部变金、旗帜升起）。
  4. 最终目标是开采演出跑满：僵尸围着矿点自动开采，金条持续喷涌铺满画面，进度条走满即胜利。
  5. **无失败条件、无重试**：不点击时金堆持续脉冲发光等玩家，玩家不可能输。

## 分析结论（流水线保留章节）

- **目标结构（动机轴）**：解压经营型（小循环嵌套大循环）。判断依据：故事板全程未出现敌人、
  血条、失败提示或任何红色威胁元素，画面压力完全来自「金条产出速度」而非生存——
  因此不套「收集→战斗力→战斗验证」，而是「收集→投资→产能爆发」。
- **操作归属**：原片为**摇杆走位**（矿工在矿盘/托盘站之间来回跑，玩家控制移动），
  playable **简化为点击**：点 3 处发光金堆收集、点 HIRE 按钮雇佣、点 CTA 跳转，
  没有虚拟摇杆、没有玩家操控角色。开采演出阶段全自动（僵尸队伍是「买来的自动化」，
  符合「自动化只能靠购买获得」原则）；除演出阶段外无自动结算。
- **目标链**：只有**一个**目标（HIRE，75 金币），开局即以按钮形式预留在场（Collect 期
  隐藏、Upgrade 期显现）。**非线性原则在本案退化**：目标只有一个，无需靠价格大小引导顺序。
  原片里的「多站点解锁 + 传送带」目标链本次不落地（见差异点 4）。
- **长期锚点与地图尺度**：基地/托盘收集站常驻画面中部（web y≈551）**开局即可见**，
  是「钱往哪儿投」的视觉锚点；矿点（web 195,495）是开采演出的喷金原点。
  地图不分层——单屏等距静态构图，无相机移动、无滚动。
- **模板映射（操作轴）**：2D collect-upgrade 模板（gold），场景 `maingame`，
  竖屏设计分辨率 720x1280（View 按 390x844 web 坐标写，经 `common/Layout.ts` 换算）。

## 资源循环

- **核心资源**：金币/金条（来源：**只有点击发光金堆**这一个来源，每堆固定面值）。
  原片里的「废料→加工」式多级资源在本 playable 中不存在。
- **循环 1 · 收集（开局即在）**：
  点击发光金堆 → 金堆消失 + 从原地爆出 8 枚金币 + 18 点火花 → 金币朝左上角
  金币面板（web 72,82）飞行归集（0.65s）→ 金币数 +25 →
  3 堆全部收完 → 自动进入雇佣期，HIRE 按钮出现。
- **循环 2 · 投资（收满后出现）**：
  点 HIRE 支付 75 金币 → 基地整体上抬 + 顶部由灰变金 + 旗帜升起 + 34 点火花 →
  僵尸矿工层（3 个）显形 → 进入开采演出。
- **循环 3 · 产能爆发（演出，无操作）**：
  僵尸向矿点方向推进 → 每 0.55s 矿点随机偏移处喷一次金币雨（8 币 + 18 火花）→
  进度条按 0.28/s 走满（约 3.6s）→ 胜利火花（web 195,338）+ 结算卡。
- **战斗循环**：**本案不存在**。原片无敌人无战斗，`showEnemies` 关闭，
  敌人层代码保留但不建树（见「地编需求」）。
- **核心逻辑**：操作重心从「一次一次点金堆」转移到「一次性大额投资」，
  之后彻底交给自动化；压力从「金币不够」转移到「等产能演出跑满」——
  全程无负向压力，靠金条雨的量感做爽点。

### 数值设计

**大小关系原则**（可调绝对值，不许破坏关系）：
1. 3 堆金堆的收益总和必须**恰好等于**一次雇佣的价格（3×25 = 75），保证「收完即刚好买得起」，不留空攒期也不出现钱不够的挫败。
2. 收集数（3 堆）要足够少，让点击期在 5 秒量级内结束——原片收集段占 20s，playable 必须压缩。
3. 开采演出时长（1/battleSpeed ≈ 3.6s）必须显著短于原片的开采段（0:41-0:52 共 11s），保证 playable 总时长可控。
4. 金币雨间隔（0.55s）必须显著小于演出时长，保证演出期至少能看到 6 次金条雨——量感是这段唯一的爽点。

| 交互点 | 需要金币数 | 备注 |
| --- | --- | --- |
| 金堆 ①②③（点击收集） | −25 / 堆（**产出**，非消耗） | 一次拾取在原片中约 4-6 根金条，按模板经济折算为 25 |
| HIRE（雇佣僵尸矿工队） | 75 | 解锁站点在原片中消耗一整背金条；对应「3 堆 = 1 次雇佣」 |

属性数值：金堆 3 处（写死在 `GoldRushModel` 的 `crates` 初始化，不在 Config 里）；
基地等级 0→1（HUD 显示 `Camp Lv.` + 等级+1）；开采进度 0→1；
单次金币爆发 8 枚 + 18 点火花；基地升级火花 34 点；胜利火花 42 点。
角色血量/伤害/耐久：**不适用**（无战斗）。
